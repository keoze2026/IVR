# README Update Rule

Whenever you make any changes to the project files, features, or architecture, you MUST update the `README.md` file to reflect those changes. 
Do not forget to keep the README.md in sync with the current state of the project.

# Project Status Rule

Before doing anything in this project, you MUST read `PROJECT_STATUS.md` first.
After completing any work, you MUST update `PROJECT_STATUS.md` to reflect the new state
(what changed, new issues, resolved issues, next steps, snapshot date and commit).
